Scale

Reads at every size.

The mark is drawn on a 64-grid. At 24 px and above use hayy-mark.svg; for 16/32 favicon sizes use favicon.svg, which has thicker pillars hand-tuned not to disappear.

Integration

Drop it in.

Inline the SVG and use currentColor so the mark themes with whatever wraps it. A copy-paste pair below — HTML/CSS for vanilla, React for components.

HTML + CSS
<a class="brand" href="/">
  <svg viewBox="0 0 64 64" width="28" height="28"
       fill="currentColor" aria-label="Hayy">
    <rect x="12" y="9"  width="9"  height="46" rx="2.2"/>
    <rect x="43" y="9"  width="9"  height="46" rx="2.2"/>
    <circle cx="32" cy="32" r="7"/>
  </svg>
  <span class="word">HAYY</span>
</a>

/* CSS */
.brand {
  display: inline-flex; align-items: center; gap: 12px;
  color: #8A3A1F;
}
.brand .word {
  font-family: 'Fraunces', Georgia, serif;
  font-weight: 500;
  letter-spacing: 0.18em;
  color: #0E0F14;
}
React
// HayyLogo.jsx
import { HayyMark, HayyLockup } from './HayyLogo.jsx';

// Just the mark — inherits color from parent.
<HayyMark size={32} style={{ color: '#8A3A1F' }} />

// Full lockup with HAYY wordmark.
<HayyLockup size={36} />

// In a button/link, theme via color.
<a className="brand" href="/">
  <HayyMark size={28} />
  <span>HAYY</span>
</a>

// Favicon — drop into .
<link rel="icon" type="image/svg+xml"
      href="/logo/favicon.svg" />
Use

How to use it well.

Do
  • Use the mark in a single brand color — clay, ink, or paper.
  • Pair with Fraunces (display) and Inter (body).
  • Let it inherit from the surrounding text color when it makes sense.
  • Reserve clear space around it equal to the diameter of the host star.
Don't
  • Outline the pillars — they're meant to be solid.
  • Add a stroke or border to the host star.
  • Rotate, skew, distort, or apply drop shadows.
  • Use the regular mark below 24 px — switch to favicon.svg instead.
  • Recreate the mark from memory. Use the SVG.
